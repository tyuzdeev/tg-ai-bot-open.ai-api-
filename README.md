Телеграм-бот с интеграцией OpenAI API и долгосрочной памятью на базе SQLite.

Стек: Python 3, pyTelegramBotAPI, OpenAI, SQLite3.

Особенности:

Реализован менеджер базы данных с использованием классов (ООП).

Управление окном контекста (Context Window), чтобы не перегружать токены API.

Сортировка хронологии истории сообщений.

Защита от сетевых таймаутов (infinity_polling).

Хранение токенов через переменные окружения (.env).
